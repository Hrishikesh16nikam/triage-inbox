# Samples

Every name, phone number, ID and address here is invented. Phone numbers use the 555-01xx range reserved for fiction, and the card number is the standard Visa test number.

`python -m triage seed-demo` turns each file in `voicemails/` into a short WAV with the text embedded as its transcript (read by the mock transcriber), and queues the files in `documents/` as-is.
